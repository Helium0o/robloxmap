Build it in Studio

  1. Open a new Baseplate place in Roblox Studio.
  2. Open View → Command Bar, paste the script, press Enter. It takes a few seconds.
  3. Press Play. Traffic and signals run on each player's device.

Everything goes in Workspace.City; the traffic lives in StarterPlayerScripts.CityTraffic. Running it again replaces both. The script also removes the default Baseplate and moves the spawn onto a sidewalk. You can also paste it into Claude Desktop and say “run this Luau in Roblox Studio”, though it's long.


      

    

  


  

    
How big can a Roblox map be?

    
There is no single “maximum map size” setting. You run into a few separate limits instead: how big one part can be, how far terrain reaches, how large the place file gets, and how precise positions stay far from the origin. For a city, the practical limit is performance (part count and memory), and instance streaming is what lets big maps work.

    

      

        
LimitValueWhat it means for a city

        
          
Largest single part hard2,048 studs per sideLong roads and big ground plates have to be split into tiles. The build script does this for you.

          
Terrain reach hard±32,000 cells (4 studs each)About 128,000 studs from the centre in each direction. You won't hit this with a city.

          
Heightmap import hard4,096 × 4,096 px1 pixel = 4 studs, so one import covers 16,384 × 16,384 studs of landscape.

          
Place file size hard100 MBSaving and publishing can fail above this. Huge detailed cities get there through duplicated meshes and unions, so reuse packages and models.

          
Instance streaming default1,024 studs target · 64 minOn by default in new places. Players only load what's near them, so a bigger map mostly costs server memory, not player frame rate.

          
Position precision soft32-bit floatsPositions get less precise the further you go from (0, 0, 0). Players report obvious glitches around 1,000,000 studs out. Keep the city centred on the origin.
